# GreenRoute AI
**Платформа моделювання та оптимізації логістики**

GreenRoute AI — B2B-платформа для моделювання, планування та оптимізації мультимодальних вантажних перевезень.
Система дозволяє формувати маршрути з використанням різних видів транспорту та оцінювати їх за часом доставки, вартістю, викидами CO₂ і прогнозованими затримками на кордонах та митниці. У разі зміни умов перевезення передбачене динамічне перепланування маршруту.

## Основні можливості
* реєстрація та авторизація користувачів;
* створення та редагування вантажних перевезень;
* визначення пунктів відправлення та призначення;
* формування маршрутів;
* підтримка мультимодальних перевезень;
* оптимізація маршрутів за часом, вартістю та CO₂;
* прогнозування затримок на кордонах і митниці;
* розрахунок вуглецевого сліду;
* динамічне перепланування маршрутів;
* моніторинг поточного стану перевезення;
* історія перевезень;
* звіти та логістична аналітика;
* адміністративне керування системою.

## Основні API
Backend надає REST API для роботи з користувачами, перевезеннями, маршрутами та сервісами оптимізації.
| Метод    | Endpoint                    | Призначення             |
| -------- | --------------------------- | ----------------------- |
| `POST`   | `/api/auth/login`           | Авторизація             |
| `GET`    | `/api/shipments`            | Список перевезень       |
| `POST`   | `/api/shipments`            | Створення перевезення   |
| `GET`    | `/api/shipments/{id}`       | Отримання перевезення   |
| `PUT`    | `/api/shipments/{id}`       | Оновлення перевезення   |
| `DELETE` | `/api/shipments/{id}`       | Видалення перевезення   |
| `POST`   | `/api/routes`               | Формування маршруту     |
| `POST`   | `/api/routes/{id}/optimize` | Оптимізація маршруту    |
| `GET`    | `/api/routes/{id}/carbon`   | Розрахунок CO₂          |
| `GET`    | `/api/routes/{id}/delay`    | Прогноз затримки        |
| `POST`   | `/api/routes/{id}/replan`   | Перепланування маршруту |
API використовує HTTP та JSON і передбачає автентифікацію для захищених операцій.

## Логіка оптимізації
Для кожного маршруту оцінюються:
* час доставки;
* вартість;
* викиди CO₂;
* прогнозовані затримки.
Показники нормалізуються та використовуються для формування підсумкової оцінки маршруту. Ваги критеріїв можуть визначатися відповідно до пріоритетів користувача.

### Розрахунок CO₂
Викиди розраховуються окремо для кожного сегмента:
CO₂ = D × M × EF
де:
* D — відстань сегмента;
* M — маса вантажу;
* EF — коефіцієнт викидів.
Загальний показник маршруту формується як сума викидів усіх його сегментів.

### Динамічне перепланування
Якщо система виявляє суттєву затримку або зміну умов перевезення:

Актуальний стан
      ↓
Виявлення відхилення
      ↓
Пошук альтернатив
      ↓
Оцінювання маршрутів
      ↓
Вибір оптимального
      ↓
Оновлення маршруту

Перепланування може запускатися автоматично або вручну користувачем.

## Запуск проєкту
Для локального запуску використовується Docker Compose. Backend, Frontend та PostgreSQL працюють у окремих контейнерах, а дані PostgreSQL зберігаються в окремому Docker volume.

### 1. Клонування репозиторію
```
git clone https://github.com/pandarov-vladyslav/GreenRoute_AI.git
cd GreenRoute_AI
```
### 2. Налаштування змінних середовища
Створіть `.env` на основі `.env.example`:
```
cp .env.example .env
```
У `.env` необхідно вказати параметри бази даних, секретний ключ JWT та ключі зовнішніх API.
```
DATABASE_URL=...
SECRET_KEY=...
MAP_API_KEY=...
ROUTING_API_KEY=...
```
Файл `.env` не повинен потрапляти до Git-репозиторію. У репозиторії зберігається лише `.env.example`.

### 3. Запуск
```
docker compose up --build
```
Після запуску доступні Frontend, Backend та PostgreSQL.
Для зупинки:
```
docker compose down
```
Docker Compose використовує окрему мережу для сервісів і зберігає дані PostgreSQL у volume `postgres_data`.
